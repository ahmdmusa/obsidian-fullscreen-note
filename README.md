# Fullscreen Note — Obsidian Plugin

View any note in fullscreen with a single click.

## Features

- Floating ⛶ button on every note
- Ribbon icon in the sidebar
- `Ctrl+Shift+F` hotkey
- Press `Esc` to exit fullscreen

## Installation

### Manual

1. Download `main.js`, `manifest.json`, `styles.css`
2. Place them in `.obsidian/plugins/fullscreen-note/`
3. Enable from Settings → Community Plugins

### Community Plugins (coming soon)

Search for **Fullscreen Note** in the Community Plugins browser.

## Compatibility

- Desktop only
- Tested on Obsidian 1.x / Fedora Linux / windows 11
